# 一、高考前（流水账）
我是从农村出来的，从农村的小学，到县城的初中，再到市中心的高中。

在我们当地，小学毕业后，初中的去向是通过抽签来决定去往我们镇上的两所初中中的一所。但我在六年级的时候就似乎被灌输了想要去县城读书的思想，当时觉得这样很有面儿hhhhh.当时我的语文老师找我谈话，也曾表示希望我能够去县城读书的，她说她教的每一届学生都有去县城读书的。当时我也是班里成绩最好的hhhh。

期末考试结束后，大概过了十几二十天，班主任打电话来告知我的成绩，并说可以去县城的初中询问是否会招收。一开始我妈妈是反对的，认为学习成绩是否好与去哪一所初中就读无关。后来在各种因素之下又同意了。……后来我便来到了县里最好的公办初中就读。

初一上，我当选班级的副班长。可惜，但在上学期没能很好履行整个职位的责任，下学期便弃职了，在之后的初中生涯里也并没有担任过任何职位。

初中的第一次月考，是我考的最差的一次。考到了年级的一百多名，班级的十几名。其实当时也没觉得有啥，但后来是班级的语文课，进行小组分组，班级前十担任组长，感觉我还是有点争抢好胜的吧，后面也默默努力提升成绩了。仍记得第二次月考考了班级第七名，期中考考了班级第九名hhhh，但在年级上还是有点进步了。

大一上的最后一次模拟考，我也是越来越进步了，考到了班级的第5名，后来老师是通过这个排名来确定 寒假的清北网校直播公益班的名额，当时叫清华北大苗子计划，这个名字还怪好听的hhhh，我们班分到了6个名额。也是从这时开始，我接触到了网络补习班。

随后来到了期末，我也是考了当时上初中以来最好的成绩。其实当时在开期中总结表彰会的时候，校长说会给年级前50的同学发奖学金，这也激励了我进一步努力学习hhhhh。

来到初一下，开学初其实没有很努力，到期中的时候成绩就掉的很厉害，期中过后便开始努力了，也感觉没什么好记录的。这学期期末也有清华北大苗子计划的公益班，我们班分配到了8个名额。我以为也是会用最后一次模拟考来作为选拔标准，但最后是用期中考试作为标准，我也是很幸运拿到了名额hhhhh。

一开学就开学考，非常的痛苦。不过当时我年级排名没有变，班级排名却拿了第1名，当时也是很开心的。

大二下我们需要进行地生中考，仍记得最后一次模拟考考了116分/120分，拿到了班级第一名，也是超级高兴啊，最后中考似乎考了112，也是班级第一名hhhh，在县里面排了前30，暑假晚上的时候突然接到班主任老师告知地生中考成绩的消息，高兴的我都睡不着觉hhhhh。

讲到这里，不得不提一提我的班主任了，可以说，在我看来，她是我学生时代遇到的所有班主任中最负责最好的班主任了，最好的廖老师，老师是教地理的，我们结束中考便不再带我们了，真的好惋惜。当时她看到我们班数学成绩不是很好，便去找领导说希望初三的时候给我们分配一位教数学的班主任老师。

到了初三，我也是比较努力，但我感觉还是多一点运气hhhh。印象最深刻的一次是，当时中午午休时拿语文书回宿舍看，每一行字我都会看，看到了“驳论”的定义，没曾想它在月考里就考了hhhhh。初三我们新学了一门化学课，开学考我就考了班级第一名，随后的期中考也是拿了班级第一名hhhh。不过第二次月考，期末考都只拿了第二名，当时我们班有拿满分的，感觉我总是差一点运气，都没拿过满分，都是错一两个空，惭愧惭愧。

上初三以来，自从第一次月考拿了班级第一名，我也越发努力了，争取捍卫一下hhhhh，最后也成功了hhhhh。不过前期在年级上的排名都是十几名，班主任还找我谈话了，希望我能努努力冲一冲hhhhh。不过期中也没冲上去。

不得不说一下我的语文成绩了，初三上的语文成绩感觉经历了好多坎坷。期末前的模拟考我的语文是所有科目中最差的，不过那次考试是我考的最好的一次，其实之后我也没有很努力学习语文，我也不知怎的，期末居然考了116.5，年级第一名，一向语文薄弱的我也是受宠若惊啊。当时班主任还找了我去谈话，说了说我的语文成绩不够高，100都没过hhhhh。不过这也只是辉煌一时了，高中的语文成绩都是起起伏伏，难以提高，尤其是高中的选择题，每次都会错一半。

到了初三下，离中考越来越近了，学习气氛越发紧张。我的体育一直以来都不太好，每次把体育成绩加上去，我的年级排名就会掉，因此我在初三下越来越努力练习体育了。仍记得我的体育成绩从初三上期末考的49，到了初三下第一次模拟考就考到了满分hhhhh，也是万万没想到哈，这个体育成绩在初三下开始的时候班主任也找我谈话了hhhh，感觉班主任找我谈话什么科目，什么科目就会提高hhhhh。真是非常感谢班主任老师的关心，很好的劳老师。可惜老师在我们毕业之后就被调到了另一个学校教书了。

之后我以市前600名的成绩去到了我们市里最好的高中，分到了筑梦班（26班），当时我的学号是1号，因此我军训时就猜测自己是不是中考成绩在这个班的排第一hhhhh
（因为前600名有没有显示成绩，所以当时我也不知道自己是多少分，当时招生也说这个班的学生都是前600的）

果不其然，就在我在10月/9月因填材料时需要填中考成绩才知道了中考考了743(/744?)/800，当时前600的分数线是715，我当时雀食挺欣喜的，仍记得中考前最后一次模拟(县里组织的第二模拟好像)我考了740，排年级11(又掉出了前十hhh)，倒数第二次模拟(考三美的卷子)，这好像是我在初三考的最高分了750还是749.5，排年级第3（惭愧惭愧，这是我高中最好的排名了），中考恰好取了个折中的，心想还是正常发挥的。

到了高一上，我同时学9科，我的成绩并没有很拔尖，第一次月考考了班级十几名，年级一百三十几，随后到了期中，我稍稍进步了，生物考了97年级第一，地理98只因涂错了一个选择题与满分擦肩而过，总排名是年级28还是29，之后是12月份联考…期末…。

开学考我考的很差，但当时物理出成了75分钟的卷子，但实际只做了60分钟，我当时做的一脸懵逼，寒假也没有学，自然考的很差了，最后出的成绩排名它没有分物理历史也没有赋分排，好像我考了一百几十名吧。

第二天我们市里有人阳了，所以停课了，我不用去学校了，之后的1个月在家上网课，而且由于我是从市区会到县城的，被通知需要隔离做核酸。真的很折磨人。

到了4月10日，是返校的日子（嘻嘻我在家待了一个月），我因为报名了生物联赛预选赛，早上很早就去学校了，10-12点做那个试卷，看着一堆不认识的名词，只能猜了，拿了62分，也非常幸运地进了省赛。

到了5月，五一只放了一天，收假回来之后就是期中考试（这种收假回来就考试真的很非人类啊，害得假期都不能好好玩），不过这次期中我超常发挥，数学考了145（这应该是我在正式考试中考的最高分的了，排了年级第一），综合考了年级19名，入选了清北之星，这是我在上高中以来最开心的时刻了。

# 二、高考后的暑假
这个为什么要单独拿出来讲呢？也是觉得是我高中生活和大学生活的一个过渡吧，挺有意义的。

高考完了，回家玩了几天。当时也想着要去练车的，结果不知道去哪里练以及找不到教练等等问题所以就先放下了。

到了6月底，高考出分的前几天，去学校听了那个志愿填报的讲座，然后顺路去防城港我姐那里玩，这也是为了逃避查分时家长及亲戚乡邻之间的迫切追问。

在防城港，出分的那天我们是去东兴玩了，当时成绩说是下午出的，结果其实中午就能查到，当时老师家长也是各种push，也有我的好奇心，我也迫不及待查了，在去吃饭的时候，我坐在车上，打开官网，登录，成绩单出来的那一刻，我率先看到的还是总分，先看到的是最后两个00，心想着总不可能是700吧，然后定神一看，看到了6，这不天塌了吗，然后就去找那个一分一段表看，七千多名，到了下车，我也没有和他们说我已经查了成绩，整个午饭完全是没有胃口的，吃得很少，有时候甚至想哭出来了，当时也点了很多，他们以为我会吃很多，最后也剩了挺多。

到了下午，我把成绩和家人说了，我没敢说出具体的数，就把最后的0打码了，当时想着到底要不要复读，一直纠结了很久，也问了一个学长和一个学姐，我也在社交平台上寻求网友们的意见，当时真的不知所措，学长建议还是要好好填志愿，可能会捡漏。后来我也好好填了。距离志愿出来还有十几二十几天的时间，当时想着那还是等结果出来再做打算吧。

然后我就自己找教练去练车了。也是练了十几天顺利过了科目二。

结果出来了，看到了投档水专，也是在意料之外的，从那开始焦虑到底要不要复读，真的犹豫了将近一个星期吧，综合了各种因素，最后才决定不复读了。后来我也从同学那里得知今年我们学校能上六百的足足有152人吧，心想这这三年来我也没考过152名的排名啊，高考也是我高中时代考的最差的一次了吧wwwwwwwww。百因必有果吧，后来我也反思了，一切都冥冥之中注定了吧。


# 三、现在
今天是5月31日端午节，我被转专业跨校区申请宿舍的成绩和电赛的准备包裹着。

距离我建立这个博客有将近小十天了吧，这些天一直在搞这个，学业有些落后了，写这篇文章也是为了给我这小十天一个小小的交代，之后直到电赛结束应该不会再来弄它了，我要好好学习专业课，高数，大物，线代了，准备期末考试了。

但这学期一直以来不知道什么原因，我对学习越来越倦怠了，现在真的很难全身心投入到学习中去，这使我真的好难受啊，玩也不能畅快得玩，学也不能安心的学。今天晚上本想着还要好好学习的，结果全用来写这篇博客了wwwwwwwww。

或许我真的是那种形式主义者吧，我想要用这篇文章来结束我对博客的过渡关注，毕竟我也有小十天浪费在它身上了，日常学习的时候也是如此，没次都是想着到整十整五的时间才放下手机，这或许也是我效率低下的原因之一吧……就先记到这吧，后面有时间会来补充的。。。。。。。
