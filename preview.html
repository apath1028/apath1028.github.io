关于这个站点

这个网站使用 Astro 构建，托管在 GitHub Pages 上。深色的背景搭配柔和的紫色调，灵感来自深夜写代码时的配色。

特色功能

  • 代码高亮 — 支持 Python、MATLAB 等多种语言，配色取自 Tokyo Night 主题
  • 数学公式 — 使用 KaTeX 渲染 LaTeX 公式，行内和块级公式都完美支持
  • 短动态 — 通过 Memos API 随时记录灵感和日常，像发朋友圈一样简单

代码示例

Python 斐波那契数列：

import numpy as np
from typing import List

def fibonacci(n: int) -> List[int]:
    """生成斐波那契数列的前 n 项"""
    if n <= 0: return []
    if n == 1: return [0]
    fib = [0, 1]
    for i in range(2, n):
        fib.append(fib[i-1] + fib[i-2])
    return fib

print(fibonacci(10))

关于我

一个喜欢记录的人

你好！欢迎来到我的数字花园。

这是一个用 Astro 构建的个人网站，托管在 GitHub Pages 上。这里记录着我的技术学习、项目经验和日常碎碎念。

关于这个网站

不像传统博客那样追求完美的"最终稿"，数字花园更像是一个持续生长的知识空间。每一篇文章都是活的——会随着我的理解加深而不断更新和演化。

核心设计理念：

  • 📝 长文章 — 通过 Markdown 文件管理，版本控制在 Git 中，确保数据的完全掌控
  • 💭 短动态 — 通过 Memos 随时随地发布，像发朋友圈一样简单，无需提交代码
  • 🎨 深色主题 — 柔和的暗色背景 + 紫色点缀，让阅读和写作都更舒适
  • 🔗 知识连接 — 文章之间通过标签和引用形成网络，而非孤立存在
